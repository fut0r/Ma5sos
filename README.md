# منصة مخصوص (Ma5sos) — لأنك المقصود · الدعوات الإلكترونية الذكية وإدارة الحضور

منصة رقمية سعودية متكاملة لتصميم الدعوات الإلكترونية للمناسبات، حفلات الزفاف، التخرج، والملكة، مع إرسال الدعوات عبر واتساب، متابعة الردود (RSVP)، وتنظيم الدخول عند البوابة عبر رموز QR مخصصة وتذاكر دخول ذكية لكل ضيف.

- الشعار والهوية: **مخصوص — لأنك المقصود** (`new-logo.png` / `src/assets/brand/logo.webp` بخلفية شفافة بالكامل)
- المستودع البرمجي: **[https://github.com/fut0r/Ma5sos.git](https://github.com/fut0r/Ma5sos.git)**

---

## المزايا والخصائص المكتملة في المشروع

1. **معرض القوالب المصورة الـ 12 الفاخرة مع تصفية ذكية:**
   - 12 قالبًا مصورًا فائق الدقة مخصصًا لمختلف المناسبات السعودية:
     - ليلة الدخلة (زواج)
     - البشت الملكي (أفراح رجالية)
     - سهرة الحنّاء (حنّاء)
     - الدبلة (ملكة وعقد قران)
     - الفلامنجو (زواج ورومانسي)
     - الورد الطائفي (زواج واحتفالات نسائية)
     - الأندلسي (زواج كلاسيكي فاخر)
     - ليالي باريس (خطوبة وأمسيات)
     - الخزامى (اجتماع عائلي ومخيمات)
     - قدها وقدود (تخرّج رسمي)
     - تخرّج طفولي (روضة وتمهيدي)
     - توتي فروتي (مواليد وعقيقة)
   - تصفية القوالب حسب نوع المناسبة في الصفحة الرئيسية، وحفظ القالب المختار تلقائيًا عند الانتقال لإنشاء المناسبة.

2. **لوحة تحكم إدارية شاملة ومطورة (`/admin/`):**
   - إضافة وتعديل وحذف المناسبات بكل سلاسة.
   - نافذة محرّر مناسبات تفاعلية مقسمة لأربعة تبويبات مع زر إدراج صيغة دعوة مقترحة تلقائيًا حسب نوع المناسبة.
   - إدارة متكاملة للمدعوين: تصفية فورية حسب حالة الضيف (الكل، مؤكد، بانتظار الرد، معتذر، حضر)، حساب دقيق لإجمالي المقاعد شاملة المرافقين، **تصدير قائمة المدعوين بملف Excel / CSV**، و**طباعة كشف الحضور** للاستقبال.
   - قيود باقة التجربة المجانية التلقائية: تتيح مناسبة واحدة فقط وبحد أقصى 3 مدعوين.
   - نافذة ترقية تفاعلية لعرض باقات مخصوص الثلاث (149، 299، 599 ر.س).

3. **ماسح رموز QR الذكي بالكاميرا (Gate Scanner):**
   - يعمل مباشرة من المتصفح عبر كاميرا الجوال أو اللابتوب مع خط ليزر متحرك وإطار استهداف، أو رفع صورة التذكرة، أو الإدخال اليدوي.
   - مسح سريع وفوري لرمز الـ QR الخاص بالضيف (`MA5SOS:TICKET:QR-...`).
   - إظهار اسم الضيف مباشرة، وحالته، وعدد المرافقين، مع منع الدخول المتكرر.

4. **صفحة الدعوة وتذاكر الدخول الرقمية الذكية للضيوف (`/invite/`):**
   - عدّاد تنازلي حي لموعد المناسبة + زر إضافة الموعد مباشرة إلى تقويم Google + رابط الموقع على Google Maps.
   - دعم كامل للروابط الخاصة بكل ضيف (`?code=...&guest=...`) والروابط العامة للمناسبة (`?code=...`).
   - لكل ضيف يؤكد حضوره يتم توليد رمز QR مشفر وفريد تمامًا مع إمكانية طباعة أو حفظ التذكرة مباشرة.

## 🛠️ التثبيت والتشغيل محليًا (Local Setup)

### 1. تثبيت المتطلبات
```bash
# تثبيت حزم واجهة React
npm install

# تثبيت حزم بايثون
python -m pip install -r requirements.txt
```

### 2. ملف البيئة
انسخ ملف `.env.example` إلى `.env.local`:
```bash
cp .env.example .env.local
```

### 3. تهيئة قاعدة البيانات محليًا
```bash
python -m api.init_db
```

### 4. تشغيل خادم التطوير
```bash
npm run dev
```
- واجهة الموقع: `http://localhost:5173`
- لوحة التحكم: `http://localhost:5173/admin/`
- توثيق الـ API (Swagger): `http://localhost:8000/api/docs`
